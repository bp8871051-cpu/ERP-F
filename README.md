# ERP Software — Enterprise React Frontend

A modern, responsive, and feature-rich ERP (Enterprise Resource Planning) frontend built with **React 18**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

## Modules Included

- **Inventory Management**: Multi-depot stock monitoring, warehouse capacity analytics, stock movement charts, run-rate forecasting, automated reorder recommendations, and inter-depot transfers.
- **Finance & Accounting**: Real-time revenue vs expenses trajectory, operating expense distribution, cash flow velocity, receivables/payables, and general ledger.
- **Enterprise CRM**: Contacts, Leads, Deals, Pipeline Kanban board, Marketing Campaigns, Customer Feedback, and Customer Analytics.
- **Procurement & Purchasing**: Purchase orders, goods receipt notes, supplier performance, and vendor ledgers.
- **Sales & Orders**: Point of Sale (POS), customer quotes, order lifecycle tracking, and invoice management.
- **Human Resources (HRM)**: Employee directories, payroll, attendance, and leave management.

## Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router v6
- **Data Visualization**: Recharts
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **HTTP Client**: Axios with Sanctum Bearer Authentication

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/bp8871051-cpu/ERP-Software-Frontend.git
cd ERP-Software-Frontend

# Install dependencies
npm install

# Start Vite dev server
npm run dev
```

### Production Build

```bash
npm run build
```
